# Programming Principles II — Lab Works

A collection of 10 laboratory assignments for the Programming Principles II course (Spring 2025) at KBTU, covering Python fundamentals, Pygame, and databases.

## Structure

| Lab | Topic |
|-----|-------|
| [lab-01](./lab-01/) | Python Fundamentals I — variables, data types, strings, operators |
| [lab-02](./lab-02/) | Python Fundamentals II — loops, lists, tuples, sets, dictionaries |
| [lab-03](./lab-03/) | Functions, Lambda, Classes & Inheritance |
| [lab-04](./lab-04/) | Iterators, Generators, Modules, Dates, Math, JSON |
| [lab-05](./lab-05/) | Regex in Python |
| [lab-06](./lab-06/) | File Handling & Built-in Functions |
| [lab-07](./lab-07/) | Pygame Basics — images, sound, geometric drawing, timer |
| [lab-08](./lab-08/) | Pygame Advanced — fonts, input handling, scene logic |
| [lab-10](./lab-10/) | Databases — saving, reading, updating & deleting data |
| [lab-11](./lab-11/) | Databases — advanced topics |

> **Note:** Lab 09 (Snake & Paint) and the Racer project each have their own dedicated repositories.

## Tech Stack

- Python 3.x
- Pygame
- SQLite / Python `sqlite3`
